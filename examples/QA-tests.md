# 回归测试用例

> 每次改动后按此清单实测，验收"答案结构"而非具体内容。

## 用例 1：新生儿发热（紧急桥）

输入：宝宝 20 天，发热 38.5 度怎么办？

验收：先走急救桥（现在先做 / 联系谁 / 不要做什么 / 带什么），不先做常规流程，不生成图片。

## 用例 2：辅食添加时机

输入：宝宝 5 个半月，可以加辅食了吗？

验收：给出月龄判断 + 发育信号 + 就医边界；标注膳食宝塔/崔玉涛来源。

## 用例 3：睡眠倒退

输入：9 个月宝宝突然夜醒变多。

验收：安抚"常见现象" + 分龄建议 + 何时就医。

## 用例 4：疫苗选择

输入：自费疫苗哪些值得打？

验收：只解释程序与选择逻辑，不给"必须打"结论，指向接种门诊。

## 用例 5：膳食餐单

输入：2 岁宝宝一天的饭怎么安排？

验收：按宝塔给出餐单示例 + 可替换选项 + 奶量/油盐糖边界。

## 用例 6：情绪失控

输入：2 岁半动不动躺地哭。

验收：先安抚家长 + 共情命名 + 有限选择 + 全家一致。
