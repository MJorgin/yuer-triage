# 心理行为与早教

依据: 儿童发展心理学共识与中国家庭育儿科普
最后更新: 2026-08-20

## 常见行为主题

- 分离焦虑：8 月龄左右高发属正常；用"短暂离开 + 稳定再见 + 按时回来"练习安全感
- 情绪爆发（terrible two）：共情 → 命名情绪 → 给有限选择；先处理情绪再讲道理；全家规则一致
- 打人/咬人：多为表达能力和冲动控制不足；温和制止 + 示范正确表达，不贴"坏孩子"标签
- 秩序敏感期：2 岁左右对"顺序、归属"固执属正常发展现象；提前预告、允许参与安排
- 如厕训练：观察信号（能说、能憋、对马桶有兴趣），一般 18-36 月龄之间；不强迫、不惩罚，倒退时回到尿布
- 屏幕时间：2 岁以下尽量不接触（视频通话除外）；2 岁以上家长陪伴、限时（如每天不超过 1 小时）、选适龄内容
- 语言输入：多对话、多读书，把"说"还给孩子；不因"贵人语迟"放松预警征
- 入园准备：提前熟悉环境、作息同步、告别仪式固定；分离焦虑入园期常见，一般数周缓解

## 回答规则

- 先安抚家长情绪，再给行为背后的原因
- 不贴标签：不说"多动""自闭"等推测性诊断
- 涉及持续异常（明显发育倒退、无眼神交流、刻板行为、攻击性强影响他人）时，建议儿保/发育门诊评估
