## 🤔 为什么

养娃不是缺知识，是缺"判断"——同样一句"宝宝发烧了"，有的在家观察就好，有的必须立刻去医院。普通 AI 会给你一长串百科式答案，但不会先问你宝宝多大、有没有建档、精神状态如何。

| | 育儿分诊台 | 直接问通用 AI |
|---|---|---|
| 认识你家娃 | ✅ 本地档案，支持多娃 | ❌ 每次从零问起 |
| 判断轻重 | ✅ 红旗症状先走急救桥 | ⚠️ 容易给百科式罗列 |
| 循证纠偏 | ✅ 内置医生立场 + 冲突裁决 | ⚠️ 可能把偏方当科普 |
| 落到三餐 | ✅ 膳食宝塔 → 一日餐单 | ⚠️ 只说"营养均衡" |
| 时效信息 | ✅ 按规则联网补充 | ⚠️ 可能用过时信息 |
| 隐私 | ✅ 档案仅存本地 | ❌ 数据经过云端 |

首次使用时直接问养娃问题即可。回答前会先建档（`~/.yuer/<宝宝昵称>/`），一次问一个问题，不用填表；多娃按昵称分目录。

## 📸 示例问答

**问：宝宝 8 个月还不会爬，正常吗？**

> 看趋势不看单点。8 个月不会爬，但会独坐、会翻身、会扶站，多数在正常范围。每个宝宝大运动节奏不同，爬行也不是必经环节。建议记录发育情况，儿保时让医生评估；如果同时不追视、不回应、四肢异常僵硬或松软，尽早去儿保科。

**问：一岁宝宝一天辅食怎么安排？**

> 参照膳食宝塔：3 餐辅食 + 1-2 次加餐，奶量约 500-600ml 并逐步让位给正餐。早餐蛋黄粥 + 软水果，午餐碎肉末青菜面，下午蒸南瓜，晚餐鱼泥软米饭。过敏宝宝先排除过敏原，量按食欲来，不强迫。

## 📚 知识来源

内置知识库是三位医生**公开科普立场的观点概括**（非原文复制），配合官方指南：

- 崔玉涛 — 日常养育：喂养、辅食、生长发育、护理
- 段涛 — 孕期产后：产后恢复、母乳困难、妈妈情绪
- 叶盛 — 循证纠偏：就医指征、用药边界、破除偏方
- 官方指南 — 中国居民膳食指南（2022 版）、国家免疫规划疫苗程序、WHO 儿童生长标准

医生观点冲突时，以官方指南和循证证据为准。来源登记见 [references/source-notes.md](references/source-notes.md)。

## 🔑 隐私

档案只存本地 `~/.yuer/`，不上传、不收集。仓库内 `data/` 仅含模板，实际档案数据永不入库。

## ⚠️ 免责声明

本 skill 提供育儿知识与观察建议，**不是医疗诊断，不替代面诊**。不诊断、不开药、不做剂量；紧急情况（红旗症状）请立即联系急救/急诊。涉及医生观点时标注"其公开科普立场"，不代表医生本人意见。
